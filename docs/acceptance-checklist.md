# 验收清单

状态标记：`NOT_RUN`、`PARTIAL`、`BLOCKED`、`PASS`。规划阶段只定义项目验收项，不代表任何实现项已通过。

## 产品与协议合同

- [ ] Owner 确认 Res、Mes、Chat 的准确含义及版本。
- [ ] 入站协议取自下游实际请求；每条路由的出站协议取自用户配置。
- [ ] 响应（含流式响应）转换回同一请求的入站协议；至少覆盖一组入站协议 A → 配置出站协议 B → 响应回转协议 A 的端到端验证（例如 Res → Chat → Res）。
- [ ] 三种入站协议与三种出站协议的支持矩阵、限制、错误和流式行为有书面定义。
- [ ] 模型别名、目标上游模型、协议转换、禁用和冲突处理语义明确。
- [ ] 上游发现模型、测试联通、超时和失败状态可解释。

## Desktop 工作区

- [ ] Desktop 打开后自动启动 Gateway，并展示启动中、运行、启动失败状态。
- [ ] 导航覆盖总览、上游、模型路由、调用日志、接入凭证和设置，不出现管理员角色或独立管理后台。
- [ ] 上游 CRUD 与测试流程含校验、加载、成功、失败、空和确认状态。
- [ ] 路由编辑清楚区分客户端入站协议与上游出站协议，并展示响应回转为入站协议。
- [ ] 接入页显示本机网关 URL；Key 创建只显示一次，并可轮换/撤销。
- [ ] 日志可筛选、查看详情；Key、上游密钥、正文默认脱敏/不记录。
- [ ] 模拟数据明确标注；真实后端接入时 UI 的错误/分页/流式边界一致。
- [ ] 响应式布局、键盘可达、焦点可见、标签/错误关联与对比度通过检查。

## Gateway 运行时与安全

- [ ] 客户端鉴权、授权范围、Key 哈希/存储、轮换/撤销与审计通过审查。
- [ ] 上游凭证不明文回显/日志；存储加密与访问边界验证。
- [ ] Gateway 默认只监听本机回环地址；连通测试限制可访问目标，验证 DNS/IP 重绑定、内网地址、重定向和超时边界。
- [ ] Desktop 退出时 Gateway 行为符合 Owner 确认的生命周期策略。
- [ ] 请求/响应大小、超时、并发、速率、重试和资源上限明确且有测试。
- [ ] 协议适配覆盖普通响应、错误、流式、工具调用及不支持能力。
- [ ] 请求关联 ID 可追踪，日志字段白名单和脱敏通过验证。

## 链路与发布

- [ ] 每个协议方向的端到端测试覆盖客户端 → 网关 → mock 上游及错误路径。
- [ ] 模型同步和连通测试对真实/模拟结果区分清楚。
- [ ] 关键指标、告警阈值、日志保留期与存储容量已确定。
- [ ] 数据库迁移、配置备份、单适配器关闭和回滚演练有证据。
- [ ] 构建、静态检查、单元/集成/E2E 结果附带命令、时间和摘要。
- [ ] 独立审查完成；Owner 对验收清单签收。

## 生命周期决策

- [ ] Owner 决定 Desktop 退出后 Gateway 停止、后台常驻或托盘驻留。
- [ ] Owner 决定是否支持开机启动、单实例与崩溃恢复。
- [ ] Owner 决定网关监听范围及局域网访问认证边界。
