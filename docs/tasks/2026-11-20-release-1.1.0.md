## Implementation

- Desktop metadata and lockfile version set to `1.1.0`.
- Settings update check uses the fixed private GitHub Releases API through the trusted Electron main/preload boundary. Each authorized app user configures a fine-grained repository `Contents: Read` token; the main process verifies it against the repository contents endpoint and stores it through `safeStorage`. It compares stable `vX.Y.Z` tags, ignores draft/prerelease records, requires the version-matched NSIS installer and GitHub's `sha256:` asset digest, and verifies downloaded bytes before executing the installer.
- Windows window and build use a product-specific routing/gateway icon from `apps/desktop/build/icon.svg` and `icon.ico`; the ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel variants.
- Final portable deliverable is one Windows x64 electron-builder `portable` `.exe` that users double-click directly. `scripts/smoke-portable.mjs` launches it with isolated temporary user data and isolated control/Gateway ports, then verifies both health endpoints. Pre-review ZIPs and portable builds are preserved and are not final Release assets.
