# Cx-Routing Gateway 1.1.3

## 更新内容

- 上游响应头等待上限提高到 5 分钟；请求体和流式响应采用统一的 10 分钟网关请求期限，支持更长时间的模型生成。
- 请求日志耗时改用单调时钟计算，并说明“首字”和“总耗时”的统计范围。
- 更新器兼容 GitHub 将安装包资产名规范化后的点号格式，同时继续校验版本路径、文件名和 SHA-256。
