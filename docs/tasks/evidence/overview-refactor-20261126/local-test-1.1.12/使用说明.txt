Cx-Routing Gateway 1.1.12 测试版

请双击桌面上的“Cx-Routing Gateway 1.1.12 测试版”快捷方式启动。

不要直接双击文件夹内的 Portable EXE；直接运行会使用程序的标准配置路径。

Gateway 地址：http://127.0.0.1:18418
本地控制端口：18419
独立配置目录：此文件夹内的 Profile
独立 Codex 配置目录：Profile\Codex

它不会自动导入正式版的配置、密钥、登录或调用日志；初次启动没有上游配置和调用数据是正常现象。
原桌面 1.1.11 程序保留，可继续使用。
